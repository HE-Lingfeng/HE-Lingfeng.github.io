# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Overview

Lingfeng He's personal academic homepage, published via GitHub Pages. Pure static HTML/CSS — no framework, no build step, no dependencies.

## Preview & Deploy

```bash
# Preview locally
python3 -m http.server 8000
# Then open http://localhost:8000

# Deploy — pushing to main publishes automatically via GitHub Pages
git push origin main
```

## Architecture

**Hand-crafted homepage (the primary surface):**
- `index.html` — semantic HTML with sections: hero, selected work, research directions, writing gallery, contact
- `css/style.css` — full visual system: CSS custom properties (design tokens), typography scale, layout, glassmorphism effects, two responsive breakpoints (900px, 560px)
- `css/fonts.css` — font stacks with CJK fallbacks
- `assets/portrait.jpg` — hero portrait

**Hugo-generated pages (legacy, mostly empty):**
- `/posts/`, `/categories/`, `/tags/`, `404.html`, `sitemap.xml`, `index.xml`
- These were generated by Hugo and are served as-is. `style.css` includes compatibility styles for Hugo list/article markup (from ~line 669 onward).
- Blog posts don't exist yet — the infrastructure is placeholder.

## Design system

- Blue-toned glassmorphism aesthetic with light color scheme
- Design tokens defined as CSS custom properties on `:root` in `style.css`
- `clamp()` based responsive typography
- If adding pages, reuse the existing CSS custom properties and class conventions rather than introducing new styling approaches

## Content philosophy (from README)

- **Homepage stays curated** — only selected publications, important projects, current research directions. Update quarterly.
- **Posts accumulate** — paper notes, experiment write-ups, project retrospectives, quiet journal entries go under `/posts/`.
- **Stack stays lightweight** — prefer semantic HTML and CSS unless the site genuinely needs search, filtering, or richer interaction.
- Add one project page per mature project (motivation, method, links, citation, figures).
